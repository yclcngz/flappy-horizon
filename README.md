# 🚀 Flappy Horizon

**Flappy Horizon**, HTML5 Canvas ve Web Audio API kullanılarak geliştirilmiş, zengin animasyonlara, 4 özelleştirilebilir karaktere ve 5 farklı tematik seviyeye sahip modern bir arcade web oyunudur.

## 🎮 Özellikler

* **🛠️ Karakter Atölyesi (Garaj):**
  * **🛸 Drone:** Model seçimi, gövde, çerçeve ve LED ışık rengi özelleştirmeleri.
  * **🦅 Kartal:** Farklı kartal ırkları, tüy rengi, kanat rengi, gaga ve göz parıltısı.
  * **🚀 Roket:** Kasa tipleri, kanatçıklar ve 4 farklı itiş alevi (Plazma, Antimadde, İyon, Ateş).
  * **🎯 Füze:** Siberpunk, Stealth ve Askeri kamuflajlar, başlık ve kıvılcım izi renkleri.
* **🌍 5 Farklı Tematik Dünya:**
  * ⚡ *Neon Siber Şehir (Halkalar ve Enerji Kapıları)*
  * 🏔️ *Alp Dağ Zirveleri*
  * 🏙️ *Metropol Gökdelenler*
  * ❄️ *Kutup Buzulları (Aurora Borealis)*
  * 🚢 *Mega Gemiler & Okyanus*
* **🕹️ Kontroller:**
  * Masaüstü: `Space`, `Yukarı Ok (↑)`, `W` veya Fare Sol Tık.
  * Mobil/Tablet: Dokunmatik ekran desteği (Touch).
* **🎵 Ses Motoru:** Prosedürel Web Audio API ses efektleri (Zıplama, Halka geçişi, Skor, Çarpışma).
* **✨ Game Feel:** Parçacık izleri, ekran sarsıntısı (Screen Shake), madalya ve en yüksek skor kaydı (LocalStorage).

## 🚀 Canlı Önizleme & Kurulum

Doğrudan `index.html` dosyasını tarayıcınızda açabilir veya herhangi bir statik web sunucusunda (Vercel, Netlify, GitHub Pages) yayınlayabilirsiniz.
